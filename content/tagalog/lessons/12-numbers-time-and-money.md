# Numbers, Time, and Money

> **The one-sentence version:** Tagalog has two complete number systems — a native one and a Spanish-derived one — and knowing which situations call for which is more useful than memorizing either perfectly.

## Why it matters

Prices, times, ages, phone numbers, how many siblings you have. This is the most practical lesson in the topic, and the two-system thing genuinely confuses learners who weren't warned.

## The native numbers

| # | Tagalog | | # | Tagalog |
|---|---|---|---|---|
| 1 | **isa** | | 11 | **labing-isa** |
| 2 | **dalawa** | | 12 | **labindalawa** |
| 3 | **tatlo** | | 13 | **labintatlo** |
| 4 | **apat** | | 20 | **dalawampu** |
| 5 | **lima** | | 21 | **dalawampu't isa** |
| 6 | **anim** | | 30 | **tatlumpu** |
| 7 | **pito** | | 50 | **limampu** |
| 8 | **walo** | | 100 | **isang daan** / **sandaan** |
| 9 | **siyam** | | 1,000 | **isang libo** / **sanlibo** |
| 10 | **sampu** | | | |

The pattern is regular once you see it: **labing-** = "ten and," **-pu** = "tens," and **'t** (short for **at**, "and") joins the leftover.

> **dalawampu't lima** = 20 + 5 = 25.

## Counting things: don't forget the linker

Numbers attach to nouns with the same linker from lesson 6:

> **isang mangga** — one mango *(isa + -ng)*
> **dalawang aso** — two dogs
> **limang taon** — five years
> **sampung piso** — ten pesos *(sampu + -ng)*

## The Spanish numbers — and when they take over

| # | Spanish-derived | | # | Spanish-derived |
|---|---|---|---|---|
| 1 | **uno** | | 15 | **kinse** |
| 2 | **dos** | | 20 | **bente** |
| 3 | **tres** | | 25 | **bente singko** |
| 4 | **kwatro** | | 30 | **trenta** |
| 5 | **singko** | | 40 | **kwarenta** |
| 6 | **sais** | | 50 | **singkwenta** |
| 7 | **siyete** | | 60 | **sisenta** |
| 8 | **otso** | | 100 | **siyento** |
| 10 | **diyes** | | | |
| 12 | **dose** | | | |

🔑 **The practical rule: money and clock time overwhelmingly use the Spanish numbers; counting things uses the native ones.** In markets you'll hear **"Singkwenta lang"** far more often than *"Limampu lang."*

That said, this varies by region, generation and context, and plenty of people mix freely. If you use the native numbers for a price, you'll be perfectly understood — you'll just sound slightly formal.

> 💡 And in Metro Manila today, **English numbers are extremely common too**, especially among younger people: *"Fifty pesos lang."* All three systems coexist in one conversation without anyone noticing.

## Telling time

Ask with:

> **Anong oras na?** — "What time is it?"
> **Anong oras ang ___?** — "What time is the ___?"

Answer with **ala-** for one o'clock and **alas-** for everything else:

| Tagalog | Time |
|---|---|
| **Ala-una** | 1:00 |
| **Alas-dos** | 2:00 |
| **Alas-singko** | 5:00 |
| **Alas-dose** | 12:00 |
| **Alas-singko y medya** | 5:30 *(y medya = "and a half")* |
| **Alas-otso kwarenta** | 8:40 |

Then add the part of the day:

| Tagalog | Meaning |
|---|---|
| **ng umaga** | in the morning |
| **ng tanghali** | at noon |
| **ng hapon** | in the afternoon |
| **ng gabi** | in the evening / at night |
| **ng madaling-araw** | in the small hours (roughly 1–5 a.m.) |

> **Alas-otso ng umaga** — 8:00 a.m.
> **Alas-siyete ng gabi** — 7:00 p.m.

**madaling-araw** is a lovely one — literally "the easy/quick day," for those hours that are neither night nor morning.

|---|---|---|---|
| **Lunes** | Monday | **Enero** | January |
| **Martes** | Tuesday | **Pebrero** | February |
| **Miyerkules** | Wednesday | **Marso** | March |
| **Huwebes** | Thursday | **Abril** | April |
| **Biyernes** | Friday | **Mayo** | May |
| **Sabado** | Saturday | **Hunyo** | June |
| **Linggo** | Sunday | **Hulyo** | July |

| | | **Oktubre** | October |
| | | **Nobyembre** | November |

All from Spanish, which makes them free if you know any Romance language.

> ⚠️ **Linggo** = Sunday; **linggo** (lowercase) = week. **Isang linggo** is "one week," **sa Linggo** is "on Sunday." Same word, and context does the disambiguating.

Useful time-frames:

> **tuwing Lunes** — every Monday
> **sa Sabado** — on Saturday
> **nitong linggo** — this week
> **noong isang linggo** — last week
> **sa susunod na linggo** — next week

## Money

The currency is the **piso** (peso); **pera** is money in general.

| Tagalog | English |
|---|---|
| **Magkano ito?** | How much is this? |
| **Magkano lahat?** | How much for everything? |
| **Singkwenta pesos.** | Fifty pesos. |
| **Mahal naman!** | That's expensive! |
| **Tawad naman po.** | A discount, please. |
| **Pwede pang bumaba?** | Can it go any lower? |
| **Sulit!** | Worth it! / Good value! |

**Tawad** — asking for a discount — is entirely normal in a **palengke** (wet market) and entirely *not* normal in a mall or a supermarket. Getting that line right saves everyone embarrassment.

## Age and quantity

> **Ilang taon ka na?** — "How old are you?"
> **Bente-singko na ako.** — "I'm 25."
> **Ilan kayo sa pamilya?** — "How many are you in the family?"
> **Lima kami.** — "There are five of us." *(kami — not including you)*

That **na** in *"Bente-singko na ako"* is the "already" particle: literally "I'm 25 already." Filipinos add it naturally when giving an age.

## Ordinals

| Tagalog | English |
|---|---|
| **una** | first |
| **ikalawa** / **pangalawa** | second |
| **ikatlo** / **pangatlo** | third |
| **ikaapat** | fourth |

> **Una ako.** — "I'm first."
> **Ikalawang anak ako.** — "I'm the second child."

## Check yourself

1. Someone at a market says **"Otsenta lang."** How much are they asking, and which number system are they using?
2. Say "three mangoes" — what's the piece learners most often drop?
3. What's the difference between **Linggo** and **linggo**?

## Key takeaways

- Two full number systems: **native** (*isa, dalawa, tatlo…*) and **Spanish-derived** (*uno, dos, tres…*), plus English in the mix.
- **Money and clock time → Spanish numbers; counting things → native numbers.** Mixing is normal.
- Numbers attach to nouns with the **linker**: *isang mangga, limang taon*.
- Time: **ala-una** for 1:00, **alas-** for the rest, plus **ng umaga / hapon / gabi**.
- Days and months are all Spanish-derived. **Linggo** = Sunday, **linggo** = week.
- **Magkano?** = how much; **tawad** (haggling) belongs in the palengke, not the mall.
- **Ilang taon ka na?** — and answers usually carry **na**.
