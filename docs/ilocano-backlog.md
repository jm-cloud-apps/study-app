# Ilocano topic backlog

Small, specific gaps in `content/ilocano`, worked top-down, one per PR. This is the
working list for the improvement loop. Tick an item when its PR is merged.

**Accuracy rule:** every new Ilocano word or phrase must come from a source
(Wikivoyage *Ilocano phrasebook*; Wikipedia *Ilokano language* / *Ilocano grammar* /
*Ilocano verbs* / *Ilocano particles*; Wiktionary) or follow a pattern the lessons
already teach. Anything unverified goes under **Needs a native speaker** instead of
into the content.
