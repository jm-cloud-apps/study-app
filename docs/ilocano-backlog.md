# Ilocano topic backlog

Small, specific gaps in `content/ilocano`, worked top-down, one per PR. This is the
working list for the improvement loop. Tick an item when its PR is merged.

**Accuracy rule:** every new Ilocano word or phrase must come from a source
(Wikivoyage *Ilocano phrasebook*; Wikipedia *Ilokano language* / *Ilocano grammar* /
*Ilocano verbs* / *Ilocano particles*; Wiktionary) or follow a pattern the lessons
already teach. Anything unverified goes under **Needs a native speaker** instead of
into the content.

## Needs a native speaker

Words a source gave but that look doubtful, or that no source confirmed. Kept out of the content until checked.

- **betis** as "foot": Wiktionary's English *foot* page lists it, but no Ilocano entry backs it, and *betis* is "calf" in Tagalog. Not used.
- **ngiwat** ("mouth"): Wiktionary marks its own translation as unchecked (`t-check`). Not used.
- **saka** ("foot / leg"): widely used, but Wiktionary has no Ilocano entry for it. Not used.
- **ita a lawas / maudi a lawas** ("this week" / "last week"): Wikivoyage glosses them the other way round (*maudi a lawas* = "this week"), which contradicts lesson 12's *maudi* = last. By the lesson's own words, *ita a lawas* = this week and *maudi a lawas* = last week, but neither is used until someone checks.
